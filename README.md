# Onde vota a seleção

Infográfico para embed (iframe) com o local de votação dos 26 convocados da seleção brasileira
para a Copa do Mundo de 2026: quem tem título no Brasil, no exterior, cancelado ou sem local
localizado. Fonte: levantamento UOL; lista de convocados FIFA World Cup 2026 – Squad List
(versão 1, 19/07/2026).

## Como embedar

Copie o conteúdo de [`embed.html`](embed.html) para o código-fonte da sua página.
O script ajusta a altura do iframe ao conteúdo.
